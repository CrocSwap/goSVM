# Security

goSVM is a public alpha: experimental and unaudited. Use it on devnets and
testnets; it is not yet recommended for programs holding production funds.

Please report a suspected vulnerability privately through GitHub's
[private vulnerability reporting](https://github.com/CrocSwap/goSVM/security/advisories/new)
rather than in a public issue. Miscompilations that could let a program behave
differently from its Go source count as security issues.
